# Contributing to the Piraeus documentation

This repository has the built documentation site that is published at <https://piraeus.io/docs/>.
The source of the documentation is the `docs/` directory in [Piraeus Operator](https://github.com/piraeusdatastore/piraeus-operator).
The `docs` workflow in Piraeus Operator builds the site with MkDocs and `mike`, and pushes it to the `gh-pages` branch of this repository.
Each deployment replaces the files of the deployed version.

Do not open pull requests in this repository.
Open them against the `docs/` directory in Piraeus Operator instead.
The [Documentation](https://github.com/piraeusdatastore/piraeus-operator/blob/v2/CONTRIBUTING.md#documentation) section of the Piraeus Operator contributing guide describes how to write and build the documentation.

The [Piraeus contributing guide](https://github.com/piraeusdatastore/piraeus/blob/master/CONTRIBUTING.md) describes how to report issues, write commits, and open pull requests.
